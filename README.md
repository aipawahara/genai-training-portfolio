# 生成AI活用・教材制作 ポートフォリオ

田村康樹（埼玉大学 工学部 電気電子物理工学科 3年）の、生成AI研修教材の制作実績と、AIエージェント活用・検証の実務ログをまとめた補足ポートフォリオです。

## 収録内容

- `docs/achievement-sheet.md` — 補足実績シート（実績1〜4＋指導バックグラウンド）
- `logs/` — 各実績の過程を示す検証ログ抜粋
  - `llm-survival-rate-limit-case.md` — 複数LLMのAPI比較検証で発生したレート制限エラーの原因切り分け記録
  - `muse-movie-1484-validation.md` — 映画リスト1,484件の統合・検証ログ（重複・表記ゆれ処理、検証方針）
  - `muse-x-797-resolution-summary.md` — Xフォロー797件のアカウント名解決サマリ（件数と手法のみ。第三者のID・ハンドルは含みません）
  - `muse-gmail-calendar-flow.md` — Gmailの予定メールをカレンダーへ自動登録する運用の設計メモ

## 主な実績

1. **生成AI活用セミナー「生成AIとの付き合い方」講義資料（全9回）** — インターンで制作し、別リポジトリで公開済み：https://github.com/aipawahara/AI_katsuyo_seminar
2. **複数LLMのAPI比較・検証環境「LLMサバイバル」** — 複数LLMをAPI連携させ同一課題で比較検証する仕組みを構築し、第1回をパイロット版として動画化
3. **AIエージェント基盤（Muse）によるデータ整理・業務自動化** — 手順設計・指示・検証というディレクション型で、データ統合と運用自動化を実施
4. **エージェント型コーディング環境（Antigravity）を用いた開発・検証** — 実績2の検証ハーネス（複数LLMのAPI呼び出し・自動ログ化プログラム）の実装

## 個人情報の取り扱い

ログ類は、第三者のID・ハンドル、組織ID、メールアドレス等の個人情報をマスクした抜粋のみを収録しています。
