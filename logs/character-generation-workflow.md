# 画像・動画生成ワークフロー記録：オリジナルキャラクター制作

手描きラフからAI生成の設定画、動画生成までを一貫して行った制作ワークフローの記録です。

## 手順

1. **手描きラフスケッチ**（本人の手描き）
   - オレンジペンによるラフ。キャラクターのシルエット、背面ユニット、アンテナ等の要素と、動きのあるポーズ案を描画。
   - 成果物：`assets/character/rough-sketch.jpg`
2. **AIによる設定画の生成**
   - ラフを起点に、生成AIで三面図形式（FRONT / SIDE / REAR）の設定画を作成。背面ユニットの構造や各部のディテールまで仕様として描き起こし、キャラクターの一貫性を担保。
   - 成果物：`assets/character/design-sheet.jpg`
3. **動画生成（Veo）**
   - 設定画のキャラクターをVeoで動画化（8秒）。3D的な質感とライティングの指定に対する生成結果を確認。
   - 成果物：`assets/character/character-video.mp4`

## 運用

生成したキャラクターは、AIアシスタントのアバターとして実際に採用し、継続使用しています（設定画を基準にアバター画像・動作バリエーションを生成）。

## 自分の役割

ラフ制作、生成指示（プロンプト設計）、候補の選定、キャラクター一貫性の品質確認。
